# 週次レポート運用：人間の作業指示書（STD）

- 作成日: 2026-07-09
- この文書は「毎週、人間がやること」**だけ**をまとめたもの。
  システム側の仕様は `spec/週次ダッシュボードv2_要件.md`、CSVの列仕様の詳細は `weekly_input_manual.md` を参照。

## 役割分担（誰が何をやるか）

| 担当 | やること |
|------|---------|
| **人間（運用者）** | 毎週火曜: 3ファイルのエクスポートとDriveアップロード（下記手順、目安20分）。完了後ダッシュボード確認・定例で投影 |
| **Codexルーティン** | 毎週火曜に自動起動。入力チェック→不足なら人間へ問い合わせ→分析実行→コメント執筆→Driveへ出力→日本語で完了報告 |
| **Codex（コーディング）** | specに基づくv2実装・改修 |
| **Claude（Fable）** | 要件定義の管理・レビュー |

## 毎週火曜の作業（6ステップ・目安20分）

### ① Drive週次フォルダを作る（1分）
- STDフォルダ: https://drive.google.com/drive/folders/127os_AXL2Rp49yEUtRKRmyoqh7WfwN11
- `weekly/` の中に実行日（火曜）の日付でフォルダを作る。例: `weekly/2026-07-14/`
- 半角英数字 `YYYY-MM-DD` 固定。

### ② Google広告：検索語句レポートを日別で出す（5分）
- 管理画面 → 検索語句レポート。
- **期間: 当月1日〜昨日（月曜）**。ただし月初の週は前週月曜まで遡って含める
  （前週月〜日の集計が必ずできるようにするため）。
- **粒度: 「日」で分割**（週別ではなく日別。2026-07から運用変更）。
- ファイル名 `ads.csv` にして①のフォルダへアップロード。
- 注意（従来どおり）: 文字コードはUTF-16のままでよい／「合計: アカウント」行は削除しない／
  出力後のCSVを手で編集しない。

### ③ Lステップ：友だち情報CSVを全量で出す（5分）
- 友だち情報（状況）エクスポート。**絞り込み・期間指定をしない全量**で出す。
  - ⚠️ 過去に絞り込み版がアップされ、歩留り%が大きく壊れた実例あり（2026-07-09週）。
    「全量で出す」がこの運用で一番重要なルール。
- 必須タグ列（STEP・決済済み・問診票提出済み・発送済み・商品5種）が含まれることを確認
  （列の詳細は `weekly_input_manual.md` の「必須タグ列」）。
- 氏名・電話・メール・住所・問診自由記述は出さない。
- ファイル名 `lstep.csv` にして①のフォルダへアップロード。

### ④ 管理表を出す（5分）
- **CSVまたはxlsxが第一希望**（PDFは数値抽出が壊れることがあるため）。
- 難しければ月別PDFを `management-YYYYMM.pdf` の名前で。**当月分と前月分の2つ**を入れる。

### ⑤ Codexルーティンに応答する（1分）
- 火曜朝にCodexルーティンが起動し、ファイルが揃っているかを確認して連絡してくる。
  - 揃っていれば自動で分析→Driveの `output/` に結果が出る。
  - 「◯◯が足りません」と来たら、不足分をアップして「アップしました」と返す。
- ルーティンが動かない・連絡がない場合は、Codexに「STDの週次レポートを実行して」と手動で指示。

### ⑥ 結果を確認して定例で使う（3分）
- **2026年7月〜: 毎週新しいExcelファイルを探す運用は廃止**。代わりに固定のGoogle
  Sheets（1つのURL、ブックマーク推奨）が実行のたびに自動更新される。URLは
  `config/std/config.yaml` の `google_sheets.spreadsheet_id` から辿れる（社内共有先は
  別途連絡）。
- 見る順番:
  1. `Dashboard`タブ上部のKPIカード（売上・垂直粗利・垂直ROAS・購入CV）
  2. **ボトルネック（今週）欄** — 5段ファネルのうち最も悪化した区間・前週比pt・
     確度（`confirmed`=前週比とトレンド比の両方で悪化継続、`single_week_noise`=
     単週の振れの可能性）を一目で表示
  3. 全期間CVR推移の折れ線グラフ（`History`タブのデータが増えるほど自動的に伸びる）
  4. 今週5段ファネルの棒グラフ
- 各週の詳細な数値根拠が欲しい場合は `History`/`Bottleneck`タブを直接参照する。
- そのまま定例で画面共有する。
- ローカル/Drive側には従来どおり `weekly_kpi.csv` / `bottlenecks.csv` /
  `analysis_meta.json` / `funnel_history.csv` が出力されるが、`weekly_dashboard.xlsx`
  は生成されなくなった。

- [ ] ECP用のGoogle Driveフォルダを作成し、URLを共有

- [ ] ECPの管理表（STDと同形式が理想）と月次粗利目標

## やってはいけないこと（重要のみ再掲）

1. **lstep.csvを絞り込みエクスポートで出す**（歩留り%が壊れる。全量が鉄則）
2. ads.csvを週別粒度で出す（日別に変更済み）
3. 週次フォルダに `ads_修正版.csv` など別名・旧版ファイルを置く（アーカイブは別フォルダへ）
4. Lステップのタグ列名を手で短縮・変更する
5. CSVをExcelで開いて保存し直す（文字化け・日付破壊の原因）
6. 氏名・電話・メール・住所・問診自由記述を含む列を出力・アップロードする
